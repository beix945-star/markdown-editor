# 在线 Markdown 文档编辑器

用于逐步学习 React 与 TypeScript 的个人项目，目标是制作一个可以编辑、预览和管理 Markdown 文档的网页工具。

## 当前状态

**准备阶段，尚未开始编写应用代码。** 当前仓库只有项目说明和学习计划，没有可运行的网页。下面列出的功能均为计划，不代表已经实现。

## 计划使用的技术

- HTML、CSS、JavaScript：页面结构、样式与交互基础。
- React、TypeScript：组件、状态管理和数据类型。
- Vite：本地开发与打包。
- Markdown 渲染库：将 Markdown 文本转换为预览内容，开发时再选定。
- localStorage：在当前浏览器中保存文档。
- Vitest：验证保存、恢复与切换文档等关键逻辑。
- Git、GitHub：记录并同步开发进度。

## 按顺序完成的功能

- [ ] 第 1 步：初始化前端，制作编辑区和预览区的静态页面。
- [ ] 第 2 步：学习 React 状态，让输入的文字即时显示在另一侧。
- [ ] 第 3 步：接入 Markdown 预览，禁用原始 HTML 并限制链接协议。
- [ ] 第 4 步：添加文档列表、新建、切换、重命名、搜索和删除。
- [ ] 第 5 步：保存到浏览器，刷新后恢复；处理读取和写入失败。
- [ ] 第 6 步：加入防抖保存，确保切换文档时内容不会丢失或写错文档。
- [ ] 第 7 步：导入、导出 Markdown 文件，检查导入格式和内容。
- [ ] 第 8 步：测试关键流程，补充截图与运行说明，再部署演示页面。

每次只实现一个小功能，理解代码并实际验证后，再勾选对应任务。

## 项目范围

第一版计划在浏览器中运行，不包含服务器、账号登录或跨设备同步。浏览器本地存储不等于云端备份，后续将用导出功能帮助备份文档。

## 如何开始

在 VS Code 中打开这个文件夹。等第一步前端初始化完成后，再补充启动命令。当前没有安装依赖或启动页面的步骤。
